## 1. 架构愿景

### 1.1 业务目标
构建一个**智能化、自动化、可扩展**的 AIOps 诊断平台，通过多 Agent 协作实现：
- 零人工干预的故障自动诊断
- 多源数据融合分析
- 根因精准定位（置信度 > 85%）
- 秒级响应时间（P99 < 10s）

### 1.2 架构愿景
- **领域驱动**: 以诊断领域为核心，清晰的领域边界
- **高内聚低耦合**: 模块职责单一，依赖倒置
- **弹性伸缩**: 支持水平扩展，云原生架构
- **可观测性**: 全链路追踪，完整的监控体系
- **可测试性**: 单元测试覆盖率 > 80%

### 1.3 技术愿景
- **Python 3.11+**: 现代异步编程
- **FastAPI**: 高性能 Web 框架
- **LangGraph**: AI Agent 编排
- **PostgreSQL + Redis**: 数据持久化与缓存
- **Kafka**: 事件驱动架构
- **Docker + K8s**: 容器化部署

## 2. 架构原则

### 2.1 SOLID 原则

#### 单一职责原则（SRP）
```
✅ 每个 Agent 只负责一种数据源的分析
✅ Repository 只负责数据访问
✅ Service 只负责业务逻辑
```

#### 开闭原则（OCP）
```
✅ 通过抽象类和接口扩展新的检测器
✅ 策略模式支持动态切换 LLM 提供者
✅ 工厂模式创建不同类型的 Agent
```

#### 里氏替换原则（LSP）
```
✅ 所有 Agent 实现统一的 BaseAgent 接口
✅ 所有 Detector 实现统一的 Detector 协议
✅ 子类可以完全替换父类
```

#### 接口隔离原则（ISP）
```
✅ 定义细粒度的协议接口
✅ 客户端只依赖需要的接口
✅ 避免胖接口
```

#### 依赖倒置原则（DIP）
```
✅ 高层模块不依赖低层模块，都依赖抽象
✅ 依赖注入管理组件生命周期
✅ 面向接口编程
```

### 2.2 设计原则

#### DRY（Don't Repeat Yourself）
- 提取公共基类和工具函数
- 使用装饰器复用横切关注点

#### KISS（Keep It Simple, Stupid）
- 优先简单方案，避免过度设计
- 渐进式演进架构

#### YAGNI（You Aren't Gonna Need It）
- 只实现当前需要的功能
- 避免提前优化

#### 关注点分离（Separation of Concerns）
- 业务逻辑与基础设施分离
- 领域模型与数据模型分离

### 3.2 核心领域对象

#### 聚合根（Aggregate Root）

```python
from dataclasses import dataclass, field
from typing import List, Optional
from datetime import datetime
from enum import Enum


class DiagnosisStatus(str, Enum):
    """诊断状态"""
    PENDING = "pending"
    COLLECTING = "collecting"
    ANALYZING = "analyzing"
    COMPLETED = "completed"
    FAILED = "failed"


@dataclass
class DiagnosisSession:
    """
    诊断会话 - 聚合根
    
    职责：
    1. 管理诊断生命周期
    2. 维护诊断状态一致性
    3. 协调证据和根因
    """
    diagnosis_id: str
    target_service: str
    time_range: 'TimeRange'
    status: DiagnosisStatus = DiagnosisStatus.PENDING
    evidences: List['Evidence'] = field(default_factory=list)
    root_causes: List['RootCause'] = field(default_factory=list)
    created_at: datetime = field(default_factory=datetime.now)
    updated_at: datetime = field(default_factory=datetime.now)
    
    def add_evidence(self, evidence: 'Evidence') -> None:
        """添加证据"""
        if self.status == DiagnosisStatus.FAILED:
            raise ValueError("Cannot add evidence to failed diagnosis")
        
        self.evidences.append(evidence)
        self._update_timestamp()
    
    def add_root_cause(self, root_cause: 'RootCause') -> None:
        """添加根因"""
        self.root_causes.append(root_cause)
        # 按置信度排序
        self.root_causes.sort(key=lambda rc: rc.confidence, reverse=True)
        self._update_timestamp()
    
    def transition_to(self, new_status: DiagnosisStatus) -> None:
        """状态转换"""
        # 状态机验证
        valid_transitions = {
            DiagnosisStatus.PENDING: [DiagnosisStatus.COLLECTING],
            DiagnosisStatus.COLLECTING: [DiagnosisStatus.ANALYZING, DiagnosisStatus.FAILED],
            DiagnosisStatus.ANALYZING: [DiagnosisStatus.COMPLETED, DiagnosisStatus.FAILED],
            DiagnosisStatus.COMPLETED: [],
            DiagnosisStatus.FAILED: []
        }
        
        if new_status not in valid_transitions[self.status]:
            raise ValueError(
                f"Invalid transition from {self.status} to {new_status}"
            )
        
        self.status = new_status
        self._update_timestamp()
    
    def get_primary_root_cause(self) -> Optional['RootCause']:
        """获取主根因（置信度最高）"""
        return self.root_causes[0] if self.root_causes else None
    
    def calculate_overall_confidence(self) -> float:
        """计算整体置信度"""
        if not self.root_causes:
            return 0.0
        
        # 加权平均
        total_weight = sum(rc.confidence for rc in self.root_causes)
        if total_weight == 0:
            return 0.0
        
        return self.root_causes[0].confidence  # 取最高置信度
    
    def _update_timestamp(self) -> None:
        """更新时间戳"""
        self.updated_at = datetime.now()
```

#### 实体（Entity）

```python
from dataclasses import dataclass
from typing import Optional
from datetime import datetime


@dataclass
class Evidence:
    """
    证据 - 实体
    
    职责：记录诊断过程中收集的证据
    """
    evidence_id: str
    type: 'EvidenceType'
    source: str
    description: str
    detail: Optional[str] = None
    weight: float = 1.0
    timestamp: datetime = field(default_factory=datetime.now)
    
    def __post_init__(self):
        """验证数据"""
        if not 0 <= self.weight <= 1:
            raise ValueError("Weight must be between 0 and 1")
        
        if not self.description:
            raise ValueError("Description cannot be empty")


@dataclass
class MetricAnomaly:
    """
    指标异常 - 实体
    
    职责：表示单个指标的异常情况
    """
    anomaly_id: str
    metric_name: str
    anomaly_type: 'AnomalyType'
    current_value: float
    baseline: float
    deviation: float
    detected_at: datetime
    confidence: float = 1.0
    
    def calculate_severity(self) -> 'SeverityLevel':
        """计算严重程度"""
        if self.deviation > 0.8:
            return SeverityLevel.CRITICAL
        elif self.deviation > 0.5:
            return SeverityLevel.HIGH
        elif self.deviation > 0.3:
            return SeverityLevel.MEDIUM
        else:
            return SeverityLevel.LOW
```

#### 值对象（Value Object）

```python
from dataclasses import dataclass
from typing import List
from datetime import datetime


@dataclass(frozen=True)
class TimeRange:
    """
    时间范围 - 值对象（不可变）
    
    职责：封装时间范围的业务逻辑
    """
    start_time: datetime
    end_time: datetime
    
    def __post_init__(self):
        """验证时间范围"""
        if self.start_time >= self.end_time:
            raise ValueError("start_time must be before end_time")
    
    @property
    def duration_seconds(self) -> int:
        """持续时间（秒）"""
        return int((self.end_time - self.start_time).total_seconds())
    
    def contains(self, timestamp: datetime) -> bool:
        """判断时间点是否在范围内"""
        return self.start_time <= timestamp <= self.end_time
    
    def overlaps(self, other: 'TimeRange') -> bool:
        """判断是否与另一个时间范围重叠"""
        return (self.start_time <= other.end_time and 
                self.end_time >= other.start_time)


@dataclass(frozen=True)
class RootCause:
    """
    根因 - 值对象（不可变）
    
    职责：封装根因分析结果
    """
    problem_type: 'ProblemType'
    description: str
    confidence: float
    reasoning: str
    recommendations: tuple  # 使用 tuple 保证不可变
    
    def __post_init__(self):
        """验证数据"""
        if not 0 <= self.confidence <= 1:
            raise ValueError("Confidence must be between 0 and 1")
        
        if not self.description:
            raise ValueError("Description cannot be empty")
    
    def is_high_confidence(self) -> bool:
        """是否高置信度"""
        return self.confidence >= 0.8


@dataclass(frozen=True)
class MetricPoint:
    """
    指标数据点 - 值对象（不可变）
    
    职责：表示单个时间点的指标值
    """
    timestamp: datetime
    value: float
    labels: tuple = ()  # 使用 tuple 保证不可变
    
    def __post_init__(self):
        """验证数据"""
        if self.value < 0:
            raise ValueError("Value cannot be negative for most metrics")
```

### 3.3 领域服务（Domain Service）

```python
from abc import ABC, abstractmethod
from typing import List, Protocol


class AnomalyDetector(ABC):
    """
    异常检测器 - 领域服务抽象
    
    职责：定义异常检测的统一接口
    """
    
    @abstractmethod
    async def detect(
        self,
        metric_name: str,
        points: List[MetricPoint]
    ) -> Optional[MetricAnomaly]:
        """检测异常"""
        pass
    
    @abstractmethod
    def get_detector_name(self) -> str:
        """获取检测器名称"""
        pass


class EvidenceAggregator:
    """
    证据聚合器 - 领域服务
    
    职责：聚合多源证据，计算权重
    """
    
    def aggregate(
        self,
        metric_anomalies: List[MetricAnomaly],
        log_anomalies: List['LogAnomaly'],
        trace_anomalies: List['TraceAnomaly']
    ) -> List[Evidence]:
        """聚合证据"""
        evidences = []
        
        # 聚合指标证据
        for anomaly in metric_anomalies:
            evidence = self._create_metric_evidence(anomaly)
            evidences.append(evidence)
        
        # 聚合日志证据
        for anomaly in log_anomalies:
            evidence = self._create_log_evidence(anomaly)
            evidences.append(evidence)
        
        # 聚合链路证据
        for anomaly in trace_anomalies:
            evidence = self._create_trace_evidence(anomaly)
            evidences.append(evidence)
        
        # 按权重排序
        evidences.sort(key=lambda e: e.weight, reverse=True)
        
        return evidences
    
    def _create_metric_evidence(self, anomaly: MetricAnomaly) -> Evidence:
        """创建指标证据"""
        weight = self._calculate_metric_weight(anomaly)
        
        return Evidence(
            evidence_id=f"metric-{anomaly.anomaly_id}",
            type=EvidenceType.METRIC,
            source=anomaly.metric_name,
            description=f"{anomaly.metric_name} 异常: "
                       f"当前值 {anomaly.current_value:.2f}, "
                       f"偏离基线 {anomaly.deviation * 100:.1f}%",
            weight=weight
        )
    
    def _calculate_metric_weight(self, anomaly: MetricAnomaly) -> float:
        """计算指标权重"""
        # 权重 = 偏离度 * 置信度
        return min(1.0, anomaly.deviation * anomaly.confidence)


class ReasoningEngine:
    """
    推理引擎 - 领域服务
    
    职责：基于证据推理根因
    """
    
    def __init__(self, llm_service: 'LLMService'):
        self.llm_service = llm_service
    
    async def infer_root_causes(
        self,
        evidences: List[Evidence]
    ) -> List[RootCause]:
        """推理根因"""
        # 构建推理上下文
        context = self._build_reasoning_context(evidences)
        
        # 调用 LLM 推理
        llm_result = await self.llm_service.analyze(context)
        
        # 解析结果
        root_causes = self._parse_llm_result(llm_result)
        
        return root_causes
    
    def _build_reasoning_context(self, evidences: List[Evidence]) -> str:
        """构建推理上下文"""
        context_parts = ["基于以下证据进行根因分析：\n"]
        
        for i, evidence in enumerate(evidences, 1):
            context_parts.append(
                f"{i}. [{evidence.type.value}] {evidence.description} "
                f"(权重: {evidence.weight:.2f})\n"
            )
        
        context_parts.append("\n请推理最可能的根因及置信度。")
        
        return "".join(context_parts)
```

```python
from abc import ABC, abstractmethod
from typing import Dict, Type


class Agent(ABC):
    """Agent 抽象基类"""
    
    @abstractmethod
    async def analyze(self, state: dict) -> dict:
        """分析方法"""
        pass


class MetricAgent(Agent):
    """指标分析 Agent"""
    async def analyze(self, state: dict) -> dict:
        # 实现指标分析逻辑
        pass


class LogAgent(Agent):
    """日志分析 Agent"""
    async def analyze(self, state: dict) -> dict:
        # 实现日志分析逻辑
        pass


class TraceAgent(Agent):
    """链路分析 Agent"""
    async def analyze(self, state: dict) -> dict:
        # 实现链路分析逻辑
        pass


class AgentFactory:
    """
    Agent 工厂
    
    职责：创建不同类型的 Agent
    优点：
    1. 封装对象创建逻辑
    2. 降低客户端与具体类的耦合
    3. 支持动态扩展新的 Agent 类型
    """
    
    _agents: Dict[str, Type[Agent]] = {
        "metric": MetricAgent,
        "log": LogAgent,
        "trace": TraceAgent
    }
    
    @classmethod
    def create(cls, agent_type: str, **kwargs) -> Agent:
        """创建 Agent"""
        agent_class = cls._agents.get(agent_type)
        
        if not agent_class:
            raise ValueError(f"Unknown agent type: {agent_type}")
        
        return agent_class(**kwargs)
    
    @classmethod
    def register_agent(cls, agent_type: str, agent_class: Type[Agent]):
        """注册新的 Agent 类型（开闭原则）"""
        cls._agents[agent_type] = agent_class
```

```python
class DiagnosisReportBuilder:
    """
    诊断报告建造者
    
    职责：逐步构建复杂的诊断报告
    优点：
    1. 分离复杂对象的构建和表示
    2. 支持链式调用
    3. 可以构建不同表示形式的报告
    """
    
    def __init__(self, diagnosis_id: str, target_service: str, time_range: TimeRange):
        self._report = DiagnosisReport(
            diagnosis_id=diagnosis_id,
            target_service=target_service,
            time_range=time_range
        )

        """添加证据"""
        self._report.evidences.append(evidence)
        return self
    
    def add_evidences(self, evidences: List[Evidence]) -> 'DiagnosisReportBuilder':
        """批量添加证据"""
        self._report.evidences.extend(evidences)
        return self
    
    def add_root_cause(self, root_cause: RootCause) -> 'DiagnosisReportBuilder':
        """添加根因"""
        self._report.root_causes.append(root_cause)
        # 自动排序
        self._report.root_causes.sort(key=lambda rc: rc.confidence, reverse=True)
        return self
    
    def set_confidence(self, confidence: float) -> 'DiagnosisReportBuilder':
        """设置置信度"""
        self._report.confidence = confidence
        return self
    
    def add_recommendation(self, recommendation: str) -> 'DiagnosisReportBuilder':
        """添加建议"""
        self._report.recommendations.append(recommendation)
        return self
    
    def add_metadata(self, key: str, value: any) -> 'DiagnosisReportBuilder':
        """添加元数据"""
        self._report.metadata[key] = value
        return self
    
    def build(self) -> DiagnosisReport:
        """构建报告"""
        # 验证报告完整性
        if not self._report.evidences:
            raise ValueError("Report must have at least one evidence")
        
        if not self._report.root_causes:
            raise ValueError("Report must have at least one root cause")
        
        # 计算整体置信度（如果未设置）

            self._report.confidence = self._calculate_confidence()
        
        return self._report
    
    def _calculate_confidence(self) -> float:
        """计算置信度"""
        if not self._report.root_causes:
            return 0.0
        return self._report.root_causes[0].confidence
```

```python
from threading import Lock
from typing import Optional


class MetricsCollector:
    """
    指标收集器单例
    
    职责：全局唯一的指标收集器
    优点：
    1. 确保只有一个实例
    2. 全局访问点
    3. 延迟初始化
    """
    
    _instance: Optional['MetricsCollector'] = None
    _lock: Lock = Lock()
    
    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                # 双重检查锁定
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
                    cls._instance._initialized = False
        return cls._instance

        if self._initialized:
            return

        self._initialized = True

        """增加计数"""
        if metric_name not in self._metrics:
            self._metrics[metric_name] = 0
        self._metrics[metric_name] += value
    
    def get_metrics(self) -> dict:
        """获取所有指标"""
        return self._metrics.copy()
```

#### 装饰器模式（Decorator Pattern）

```python
from functools import wraps
from typing import Callable
import time
import logging


def with_retry(max_retries: int = 3, delay: float = 1.0):
    """
    重试装饰器
    
    职责：为函数添加重试逻辑
    优点：
    1. 不修改原函数代码
    2. 可组合使用多个装饰器
    3. 符合开闭原则
    """
    def decorator(func: Callable):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            last_exception = None
            
            for attempt in range(max_retries):
                try:
                    return await func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    if attempt < max_retries - 1:
                        await asyncio.sleep(delay * (attempt + 1))
                    logging.warning(
                        f"Attempt {attempt + 1}/{max_retries} failed: {e}"
                    )
            
            raise last_exception
        
        return wrapper
    return decorator


def with_cache(ttl: int = 3600):
    """
    缓存装饰器
    
    职责：为函数添加缓存功能
    """
    def decorator(func: Callable):
        cache = {}
        
        @wraps(func)
        async def wrapper(*args, **kwargs):
            # 生成缓存键
            cache_key = f"{func.__name__}:{args}:{kwargs}"
            
            # 检查缓存
            if cache_key in cache:
                cached_value, cached_time = cache[cache_key]
                if time.time() - cached_time < ttl:
                    return cached_value
            
            # 执行函数
            result = await func(*args, **kwargs)
            
            # 写入缓存
            cache[cache_key] = (result, time.time())
            
            return result
        
        return wrapper
    return decorator


def with_metrics(metric_name: str):
    """
    指标装饰器
    
    职责：为函数添加指标收集
    """
    def decorator(func: Callable):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            start_time = time.time()
            
            try:
                result = await func(*args, **kwargs)
                # 记录成功
                metrics_collector.increment(f"{metric_name}_success")
                return result
            except Exception as e:
                # 记录失败
                metrics_collector.increment(f"{metric_name}_failure")
                raise
            finally:
                # 记录耗时
                duration = time.time() - start_time
                metrics_collector.observe(f"{metric_name}_duration", duration)
        
        return wrapper
    return decorator
```

```python
        self._cache = cache_service
```

#### 组合模式（Composite Pattern）

```python
from abc import ABC, abstractmethod
from typing import List


class DetectionRule(ABC):
    """检测规则抽象"""
    
    @abstractmethod
    async def evaluate(self, data: dict) -> bool:
        """评估规则"""
        pass


class SimpleRule(DetectionRule):
    """简单规则（叶子节点）"""
    
    def __init__(self, condition: Callable[[dict], bool]):
        self._condition = condition
    
    async def evaluate(self, data: dict) -> bool:
        return self._condition(data)


class CompositeRule(DetectionRule):
    """
    组合规则（组合节点）
    
    职责：组合多个规则，支持复杂逻辑
    优点：
    1. 统一处理单个对象和组合对象
    2. 支持递归组合
    3. 易于扩展新规则
    """
    
    def __init__(self, operator: str = "AND"):
        self._rules: List[DetectionRule] = []
        self._operator = operator  # AND, OR
    
    def add_rule(self, rule: DetectionRule) -> 'CompositeRule':
        """添加子规则"""
        self._rules.append(rule)
        return self
    
    def remove_rule(self, rule: DetectionRule) -> 'CompositeRule':
        """移除子规则"""
        self._rules.remove(rule)
        return self
    
    async def evaluate(self, data: dict) -> bool:
        """评估组合规则"""
        if not self._rules:
            return True
        
        results = [await rule.evaluate(data) for rule in self._rules]
        
        if self._operator == "AND":
            return all(results)
        elif self._operator == "OR":
            return any(results)
        else:
            raise ValueError(f"Unknown operator: {self._operator}")


# 使用示例：构建复杂规则树
# (CPU > 80% AND Memory > 90%) OR (ErrorRate > 5%)

cpu_rule = SimpleRule(lambda data: data.get("cpu", 0) > 0.8)
memory_rule = SimpleRule(lambda data: data.get("memory", 0) > 0.9)
error_rate_rule = SimpleRule(lambda data: data.get("error_rate", 0) > 0.05)

resource_rules = CompositeRule("AND").add_rule(cpu_rule).add_rule(memory_rule)
root_rule = CompositeRule("OR").add_rule(resource_rules).add_rule(error_rate_rule)

# 评估规则
result = await root_rule.evaluate({
    "cpu": 0.85,
    "memory": 0.95,
    "error_rate": 0.02
})  # True
```

### 5.3 行为型模式

#### 策略模式（Strategy Pattern）

```python
from abc import ABC, abstractmethod
from typing import List


class AnomalyDetectionStrategy(ABC):
    """
    异常检测策略接口
    
    职责：定义异常检测算法的统一接口
    """
    
    @abstractmethod
    async def detect(
        self,
        metric_name: str,
        points: List[MetricPoint]
    ) -> Optional[MetricAnomaly]:
        """检测异常"""
        pass


class ThresholdStrategy(AnomalyDetectionStrategy):
    """阈值检测策略"""
    
    def __init__(self, thresholds: dict):
        self._thresholds = thresholds
    
    async def detect(
        self,
        metric_name: str,
        points: List[MetricPoint]
    ) -> Optional[MetricAnomaly]:
        """基于阈值检测"""
        threshold = self._thresholds.get(metric_name)
        if not threshold:
            return None
        
        # 检测逻辑
        recent_points = points[-5:]
        exceed_count = sum(1 for p in recent_points if p.value > threshold)
        
        if exceed_count >= 3:
            return MetricAnomaly(
                anomaly_id=str(uuid.uuid4()),
                metric_name=metric_name,
                anomaly_type=AnomalyType.SPIKE,
                current_value=recent_points[-1].value,
                baseline=threshold,
                deviation=(recent_points[-1].value - threshold) / threshold,
                detected_at=datetime.now()
            )
        
        return None


class StatisticalStrategy(AnomalyDetectionStrategy):
    """统计检测策略（3-sigma）"""
    
    async def detect(
        self,
        metric_name: str,
        points: List[MetricPoint]
    ) -> Optional[MetricAnomaly]:
        """基于统计学检测"""
        import numpy as np
        
        values = [p.value for p in points]
        mean = np.mean(values)
        std = np.std(values)
        
        current_value = points[-1].value
        z_score = abs((current_value - mean) / std) if std > 0 else 0
        
        if z_score > 3:  # 3-sigma
            return MetricAnomaly(
                anomaly_id=str(uuid.uuid4()),
                metric_name=metric_name,
                anomaly_type=AnomalyType.SPIKE,
                current_value=current_value,
                baseline=mean,
                deviation=z_score / 3,
                detected_at=datetime.now()
            )
        
        return None


class MLStrategy(AnomalyDetectionStrategy):
    """机器学习检测策略"""
    
    def __init__(self, model):
        self._model = model
    
    async def detect(
        self,
        metric_name: str,
        points: List[MetricPoint]
    ) -> Optional[MetricAnomaly]:
        """基于机器学习检测"""
        # 使用训练好的模型预测
        features = self._extract_features(points)
        is_anomaly = self._model.predict([features])[0]
        
        if is_anomaly:
            return MetricAnomaly(
                anomaly_id=str(uuid.uuid4()),
                metric_name=metric_name,
                anomaly_type=AnomalyType.ML_DETECTED,
                current_value=points[-1].value,
                baseline=self._model.predict_baseline(features),
                deviation=0.8,  # ML 置信度
                detected_at=datetime.now()
            )
        
        return None
    
    def _extract_features(self, points: List[MetricPoint]) -> list:
        """特征提取"""
        import numpy as np
        values = [p.value for p in points]
        return [
            np.mean(values),
            np.std(values),
            np.max(values),
            np.min(values)
        ]


class AnomalyDetectorContext:
    """
    异常检测器上下文
```

```python
from abc import ABC, abstractmethod
from typing import Optional


class EvidenceValidator(ABC):
    """
    证据验证器接口
    
    职责：定义证据验证的统一接口
    """
    
    def __init__(self):
        self._next_validator: Optional['EvidenceValidator'] = None
    
    def set_next(self, validator: 'EvidenceValidator') -> 'EvidenceValidator':
        """设置下一个验证器"""
        self._next_validator = validator
        return validator
    
    async def validate(self, evidence: Evidence) -> bool:
        """验证证据"""
        # 当前验证器处理
        if not await self._do_validate(evidence):
            return False
        
        # 传递给下一个验证器
        if self._next_validator:
            return await self._next_validator.validate(evidence)
        
        return True
    
    @abstractmethod
    async def _do_validate(self, evidence: Evidence) -> bool:
        """子类实现具体验证逻辑"""
        pass


class WeightValidator(EvidenceValidator):
    """权重验证器"""
    
    async def _do_validate(self, evidence: Evidence) -> bool:
        """验证权重范围"""
        return 0 <= evidence.weight <= 1


class SourceValidator(EvidenceValidator):
    """来源验证器"""
    
    async def _do_validate(self, evidence: Evidence) -> bool:
        """验证来源合法性"""
        valid_sources = ["metric", "log", "trace"]
        return evidence.type.value in valid_sources


class ContentValidator(EvidenceValidator):
    """内容验证器"""
    
    async def _do_validate(self, evidence: Evidence) -> bool:
        """验证内容完整性"""
        return bool(evidence.description and evidence.source)


class DuplicateValidator(EvidenceValidator):
    """重复验证器"""
    
    def __init__(self, existing_evidences: List[Evidence]):
        super().__init__()
        self._existing = existing_evidences
    
    async def _do_validate(self, evidence: Evidence) -> bool:
        """验证是否重复"""
        for existing in self._existing:
            if (existing.source == evidence.source and 
                existing.description == evidence.description):
                return False
        return True


# 构建验证链
def create_evidence_validation_chain(
    existing_evidences: List[Evidence]
) -> EvidenceValidator:
    """
    创建证据验证链
    
    优点：
    1. 解耦验证逻辑
    2. 动态组合验证器
    3. 易于扩展新验证器
    """
    weight_validator = WeightValidator()
    source_validator = SourceValidator()
    content_validator = ContentValidator()
    duplicate_validator = DuplicateValidator(existing_evidences)
    
    # 链接验证器
    weight_validator.set_next(source_validator).set_next(
        content_validator
    ).set_next(duplicate_validator)
    
    return weight_validator


# 使用示例

    type=EvidenceType.METRIC,
    source="cpu_usage",
    description="CPU 使用率异常",
    weight=0.85
)

is_valid = await validator_chain.validate(new_evidence)
```

```python
from abc import ABC, abstractmethod


class BaseAgent(ABC):
    """
    Agent 抽象基类
    
    职责：定义 Agent 执行的模板流程
    优点：
    1. 固定算法骨架
    2. 子类实现具体步骤
    3. 代码复用
    """
    
    async def analyze(self, state: dict) -> dict:
        """
        模板方法：定义分析流程
        
        流程：
        1. 验证输入
        2. 采集数据
        3. 检测异常
        4. 增强分析
        5. 更新状态
        """
        # 1. 验证输入
        await self._validate_input(state)
        
        # 2. 采集数据
        data = await self._collect_data(state)
        
        # 3. 检测异常
        anomalies = await self._detect_anomalies(data)
        
        # 4. 增强分析（可选）
        if anomalies:
            await self._enhance_analysis(anomalies)
        
        # 5. 更新状态
        state = await self._update_state(state, anomalies)
        
        return state
    
    async def _validate_input(self, state: dict):
        """验证输入（钩子方法）"""
        if not state.get("target_service"):
            raise ValueError("target_service is required")
    
    @abstractmethod
    async def _collect_data(self, state: dict) -> dict:
        """采集数据（抽象方法，子类必须实现）"""
        pass
    
    @abstractmethod
    async def _detect_anomalies(self, data: dict) -> List:
        """检测异常（抽象方法，子类必须实现）"""
        pass
    
    async def _enhance_analysis(self, anomalies: List):
        """增强分析（钩子方法，子类可选实现）"""
        pass  # 默认空实现
    
    async def _update_state(self, state: dict, anomalies: List) -> dict:
        """更新状态（具体方法）"""
        state[f"{self.get_agent_type()}_anomalies"] = [
            vars(a) for a in anomalies
        ]
        return state
    
    @abstractmethod
    def get_agent_type(self) -> str:
        """获取 Agent 类型"""
        pass


class MetricAgent(BaseAgent):
    """指标分析 Agent（具体子类）"""
    
    def __init__(self, prometheus_client, detector, llm_service):
        self._prometheus = prometheus_client
        self._detector = detector
        self._llm = llm_service
    
    async def _collect_data(self, state: dict) -> dict:
        """实现指标数据采集"""
        service = state["target_service"]
        start = state["start_time"]
        end = state["end_time"]
        
        return {
            "cpu": await self._prometheus.query_range(
                f"cpu_usage{{service='{service}'}}", start, end
            ),
            "memory": await self._prometheus.query_range(
                f"memory_usage{{service='{service}'}}", start, end
            )
        }
    
    async def _detect_anomalies(self, data: dict) -> List[MetricAnomaly]:
        """实现指标异常检测"""
        anomalies = []
        
        for metric_name, points in data.items():
            anomaly = await self._detector.detect(metric_name, points)
            if anomaly:
                anomalies.append(anomaly)
        
        return anomalies
    
    async def _enhance_analysis(self, anomalies: List[MetricAnomaly]):
        """重写：使用 LLM 增强分析"""
        prompt = self._build_prompt(anomalies)
        llm_insight = await self._llm.analyze(prompt)
        
        for anomaly in anomalies:
            anomaly.llm_insight = llm_insight
    
    def get_agent_type(self) -> str:
        return "metric"
```

```python
class DiagnosisOrchestrator:

    诊断编排服务
    
    职责：
    1. 编排多个 Agent 协作
    2. 管理诊断生命周期
    3. 协调数据流转

    - 外观模式：简化复杂子系统调用
    - 中介者模式：协调 Agent 间交互
    """

        self,

        log_agent: LogAgent,
        trace_agent: TraceAgent,
        rca_agent: RCAAgent,
        diagnosis_repository: DiagnosisRepository,
        event_bus: 'EventBus'
    ):
        self._metric_agent = metric_agent
        self._log_agent = log_agent
        self._trace_agent = trace_agent
        self._rca_agent = rca_agent
        self._repository = diagnosis_repository
        self._event_bus = event_bus
    
    async def diagnose(self, diagnosis_id: str, target_service: str, time_range: TimeRange):
        """
        执行诊断
        
        流程：
        1. 创建诊断会话
        2. 并行采集数据
        3. 根因分析
        4. 生成报告
        5. 持久化
        """
        try:
            # 1. 创建诊断会话
            session = DiagnosisSession(
                diagnosis_id=diagnosis_id,
                target_service=target_service,
                time_range=time_range
            )
            
            # 发布事件：诊断开始
            await self._event_bus.publish(DiagnosisEvent(
                "diagnosis_started",
                {"diagnosis_id": diagnosis_id}
            ))
            
            # 2. 并行采集数据
            session.transition_to(DiagnosisStatus.COLLECTING)
            
            state = {
                "diagnosis_id": diagnosis_id,
                "target_service": target_service,
                "start_time": time_range.start_time,
                "end_time": time_range.end_time
            }
            
            # 并行执行 Agent
            results = await asyncio.gather(
                self._metric_agent.analyze(state.copy()),
                self._log_agent.analyze(state.copy()),
                self._trace_agent.analyze(state.copy()),
                return_exceptions=True
            )
            
            # 合并结果
            for result in results:
                if isinstance(result, Exception):
                    logging.error(f"Agent failed: {result}")
                    continue
                state.update(result)
            
            # 3. 根因分析
            session.transition_to(DiagnosisStatus.ANALYZING)
            
            rca_result = await self._rca_agent.analyze(state)
            
            # 添加证据和根因到会话
            for evidence_data in rca_result.get("evidences", []):
                evidence = Evidence(**evidence_data)
                session.add_evidence(evidence)
            
            for root_cause_data in rca_result.get("root_causes", []):
                root_cause = RootCause(**root_cause_data)
                session.add_root_cause(root_cause)
            
            # 4. 生成报告
            report = await self._generate_report(session)
            
            # 5. 持久化
            await self._repository.save(session)
            
            # 完成
            session.transition_to(DiagnosisStatus.COMPLETED)
            
            # 发布事件：诊断完成
            await self._event_bus.publish(DiagnosisEvent(
                "diagnosis_completed",
                {
                    "diagnosis_id": diagnosis_id,
                    "confidence": session.calculate_overall_confidence()
                }
            ))
            
            return report
        
        except Exception as e:
            # 失败处理
            session.transition_to(DiagnosisStatus.FAILED)
            
            await self._event_bus.publish(DiagnosisEvent(
                "diagnosis_failed",
                {"diagnosis_id": diagnosis_id, "error": str(e)}
            ))
            
            raise
    
    async def _generate_report(self, session: DiagnosisSession) -> DiagnosisReport:
        """生成诊断报告（使用建造者模式）"""
        builder = DiagnosisReportBuilder(
            diagnosis_id=session.diagnosis_id,
            target_service=session.target_service,
            time_range=session.time_range
        )
        
        builder.add_evidences(session.evidences)
        
        for root_cause in session.root_causes:
            builder.add_root_cause(root_cause)
            # 添加建议
            for recommendation in root_cause.recommendations:
                builder.add_recommendation(recommendation)
        
        builder.set_confidence(session.calculate_overall_confidence())
        
        return builder.build()
```

```python
from typing import Dict, Callable, Any
from dataclasses import dataclass


@dataclass
class ServiceDescriptor:
    """服务描述符"""
    service_type: type
    implementation: Callable
    lifetime: str  # singleton, transient, scoped


class DIContainer:
    """
    依赖注入容器
    
    职责：
    1. 管理服务生命周期
    2. 解析依赖关系
    3. 自动装配
    
    优点：
    1. 控制反转（IoC）
    2. 降低耦合
    3. 便于测试
    """
    
    def __init__(self):
        self._services: Dict[type, ServiceDescriptor] = {}
        self._singletons: Dict[type, Any] = {}
    
    def register_singleton(
        self,
        service_type: type,
        implementation: Callable = None
    ):
        """注册单例服务"""
        if implementation is None:
            implementation = service_type
        
        self._services[service_type] = ServiceDescriptor(
            service_type=service_type,
            implementation=implementation,
            lifetime="singleton"
        )
    
    def register_transient(
        self,
        service_type: type,
        implementation: Callable = None
    ):
        """注册瞬态服务"""
        if implementation is None:
            implementation = service_type
        
        self._services[service_type] = ServiceDescriptor(
            service_type=service_type,
            implementation=implementation,
            lifetime="transient"
        )
    
    def resolve(self, service_type: type) -> Any:
        """解析服务"""
        descriptor = self._services.get(service_type)
        
        if not descriptor:
            raise ValueError(f"Service {service_type} not registered")
        
        # 单例
        if descriptor.lifetime == "singleton":
            if service_type not in self._singletons:
                self._singletons[service_type] = self._create_instance(
                    descriptor.implementation
                )
            return self._singletons[service_type]
        
        # 瞬态
        return self._create_instance(descriptor.implementation)
    
    def _create_instance(self, implementation: Callable) -> Any:
        """创建实例（自动解析依赖）"""
        import inspect
        
        # 获取构造函数参数
        sig = inspect.signature(implementation.__init__)
        params = {}
        
        for param_name, param in sig.parameters.items():
            if param_name == "self":
                continue
            
            # 解析参数类型
            param_type = param.annotation
            if param_type != inspect.Parameter.empty:
                # 递归解析依赖
                params[param_name] = self.resolve(param_type)
        
        # 创建实例
        return implementation(**params)
```

```python
            start_time=session.time_range.start_time,

            primary_problem_type=session.get_primary_root_cause().problem_type 
                if session.root_causes else None,
            confidence=session.calculate_overall_confidence(),
            root_causes_json=json.dumps([
                {
                    "problem_type": rc.problem_type.value,
                    "description": rc.description,
                    "confidence": rc.confidence,
                    "reasoning": rc.reasoning,
                    "recommendations": list(rc.recommendations)
                }
                for rc in session.root_causes
            ]),
            evidences_json=json.dumps([
                {
                    "evidence_id": e.evidence_id,
                    "type": e.type.value,
                    "source": e.source,
                    "description": e.description,
                    "detail": e.detail,
                    "weight": e.weight
                }
                for e in session.evidences
            ]),
            status=session.status,
            generated_at=datetime.now() if session.status == DiagnosisStatus.COMPLETED else None,
            created_at=session.created_at,
            updated_at=session.updated_at
        )
    
    def to_domain(self, model: DiagnosisReportModel) -> DiagnosisSession:
        """ORM 模型 -> 领域对象"""
        import json
        
        session = DiagnosisSession(
            diagnosis_id=model.diagnosis_id,
            target_service=model.target_service,
            time_range=TimeRange(
                start_time=model.start_time,
                end_time=model.end_time
            ),
            status=model.status,
            created_at=model.created_at,
            updated_at=model.updated_at
        )
        
        # 恢复证据
        if model.evidences_json:
            evidences_data = json.loads(model.evidences_json)
            for e_data in evidences_data:
                session.add_evidence(Evidence(
                    evidence_id=e_data["evidence_id"],
                    type=EvidenceType(e_data["type"]),
                    source=e_data["source"],
                    description=e_data["description"],
                    detail=e_data.get("detail"),
                    weight=e_data["weight"]
                ))
        
        # 恢复根因
        if model.root_causes_json:
            root_causes_data = json.loads(model.root_causes_json)
            for rc_data in root_causes_data:
                session.add_root_cause(RootCause(
                    problem_type=ProblemType(rc_data["problem_type"]),
                    description=rc_data["description"],
                    confidence=rc_data["confidence"],
                    reasoning=rc_data["reasoning"],
                    recommendations=tuple(rc_data["recommendations"])
                ))
        
        return session
```

### 7.3 缓存装饰器

```python
from functools import wraps
import hashlib
import json
from typing import Callable


def cached(
    ttl: int = 3600,
    key_prefix: str = "",
    serializer: Callable = json.dumps,
    deserializer: Callable = json.loads
):
    """
    缓存装饰器
    
    职责：自动缓存方法返回值
    优点：
    1. 减少重复计算
    2. 降低数据库/API 压力
    3. 提升响应速度
    """
    def decorator(func: Callable):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            # 获取 Redis 客户端
            redis_service = get_redis_service()
            
            # 生成缓存键
            cache_key = _generate_cache_key(
                key_prefix or func.__name__,
                args,
                kwargs
            )
            
            # 检查缓存
            cached_value = await redis_service.get(cache_key)
            if cached_value:
                return deserializer(cached_value)
            
            # 执行函数
            result = await func(*args, **kwargs)
            
            # 写入缓存
            await redis_service.set(
                cache_key,
                serializer(result),
                ex=ttl
            )
            
            return result
        
        return wrapper
    return decorator


def _generate_cache_key(prefix: str, args: tuple, kwargs: dict) -> str:
    """生成缓存键"""
    # 序列化参数
    params_str = json.dumps({
        "args": args[1:],  # 跳过 self
        "kwargs": kwargs
    }, sort_keys=True)
    
    # 生成哈希
    hash_value = hashlib.md5(params_str.encode()).hexdigest()
    
    return f"{prefix}:{hash_value}"
```

### 8.2 CQRS（命令查询职责分离）

```python
from abc import ABC, abstractmethod


class Command(ABC):
    """命令基类"""
    pass


class Query(ABC):
    """查询基类"""
    pass


class CommandHandler(ABC):
    """命令处理器接口"""
    
    @abstractmethod
    async def handle(self, command: Command):
        pass


class QueryHandler(ABC):
    """查询处理器接口"""
    
    @abstractmethod
    async def handle(self, query: Query):
        pass


class CommandBus:
    """
    命令总线
    
    职责：路由命令到对应的处理器
    优点：
    1. 解耦发送者和处理器
    2. 支持管道（中间件）
    3. 易于扩展
    """
    
    def __init__(self):
        self._handlers: Dict[type, CommandHandler] = {}
        self._middlewares: List[Callable] = []
    
    def register_handler(
        self,
        command_type: type,
        handler: CommandHandler
    ):
        """注册处理器"""
        self._handlers[command_type] = handler
    
    def add_middleware(self, middleware: Callable):
        """添加中间件"""
        self._middlewares.append(middleware)
    
    async def dispatch(self, command: Command):
        """分发命令"""
        handler = self._handlers.get(type(command))
        
        if not handler:
            raise ValueError(f"No handler registered for {type(command)}")
        
        # 执行中间件管道
        async def pipeline():
            for middleware in self._middlewares:
                await middleware(command)
            
            # 执行处理器
            return await handler.handle(command)
        
        return await pipeline()


# 使用示例
command_bus = CommandBus()

# 注册处理器
command_bus.register_handler(
    TriggerDiagnosisCommand,
    TriggerDiagnosisCommandHandler(orchestrator)
)

# 添加中间件
command_bus.add_middleware(logging_middleware)
command_bus.add_middleware(validation_middleware)

# 分发命令
await command_bus.dispatch(TriggerDiagnosisCommand(
    target_service="user-service",
    start_time=start,
    end_time=end
))
```

- ✅ 快速集成 AI 能力

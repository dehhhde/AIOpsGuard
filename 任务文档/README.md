## 📊 项目结构预览

```
AIOpsGuard/
├── aiops-agent/              # 诊断 Agent（Python）
│   ├── domain/               # 领域层（核心业务逻辑）
│   ├── application/          # 应用服务层
│   ├── infrastructure/       # 基础设施层
│   ├── adapters/             # 适配器层（API、事件）
│   ├── shared/               # 共享内核
│   ├── config/               # 配置
│   └── tests/                # 测试
│
├── target-app/               # 被测应用（Spring Boot）
│   └── src/main/java/...     # 故障注入接口
│
├── frontend/                 # 前端（Vue 3）
│   ├── src/
│   │   ├── views/            # 页面组件
│   │   ├── components/       # 公共组件
│   │   └── stores/           # 状态管理
│   └── package.json
│
├── infrastructure/           # 基础设施配置
│   ├── prometheus/           # Prometheus 配置
│   ├── loki/                 # Loki 配置
│   ├── tempo/                # Tempo 配置
│   ├── grafana/              # Grafana Dashboard
│   └── k8s/                  # Kubernetes YAML
│
├── docker-compose.yml        # 本地开发环境
└── 任务文档/                 # 本系列文档
    ├── 00-总览与规划.md
    ├── 01-项目初始化与环境准备.md
    ├── 02-领域模型实现.md
    └── ...
```

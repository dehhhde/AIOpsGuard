## 三、Mock 数据与进度模拟

### 3.1 Mock 数据结构

✅ **核心类型定义**（types/diagnosis.ts）
- DiagnosisSession：会话完整模型
- RootCause：根因与置信度
- Evidence：三类证据统一接口
- DiagnosisStatus：4 种状态（pending/analyzing/completed/failed）

✅ **Mock 数据案例**（mock/data/）
- 1 个已完成诊断（包含完整根因、证据、报告）
- 1 个进行中诊断（用于测试进度更新）

### 3.2 进度推送模拟

✅ **WebSocket Mock**（mock/ws.ts）
- 每 2 秒推进一个阶段（采集 → 指标 → 日志 → 链路 → RCA → 报告）
- 自动发送 `diagnosis.progress` 事件
- 完成后发送 `diagnosis.completed` 事件
- 订阅后立即回放当前状态

✅ **Mock 开关**
- 环境变量 `VITE_USE_MOCK=true` 控制
- 可无缝切换到真实 API

## 四、Grafana 深链实现

✅ **深链参数**（utils/grafana.ts）
```typescript
buildGrafanaUrl({
  service: 'target-app',           // 服务名
  instance: '192.168.1.10:8080',   // 实例地址
  from: '2026-11-16T10:00:00Z',    // 开始时间（时间戳）
  to: '2026-11-16T10:05:00Z',      // 结束时间（时间戳）
  dashboardUid: 'aiops-target-app-jvm', // Dashboard UID
  panelId: 12,                     // Panel ID（可选）
})
```

✅ **证据类型映射**
- METRIC → `aiops-target-app-jvm`
- LOG → `aiops-target-app-logs`

✅ **用户体验**
- 证据卡片中"查看原始数据"按钮直接跳转

### 6.2 后端 API 要求

**REST 接口**：
- `GET /api/v1/diagnosis`：列表（支持分页、筛选）
- `GET /api/v1/diagnosis/{id}`：详情
- `GET /api/v1/diagnosis/{id}/report`：报告
- `GET /api/v1/diagnosis/{id}/metrics`：指标摘要
- `GET /api/v1/diagnosis/history`：历史记录
- `POST /api/v1/diagnosis`：触发诊断

**WebSocket 接口**：
- 连接路径：`/ws/diagnosis/{id}`
- 事件类型：`diagnosis.progress`、`diagnosis.completed`、`diagnosis.failed`
- 报文字段：`diagnosisId`、`status`、`stage`、`progress`、`timestamp`

**字段契约**：
- 后端返回的 JSON 字段需与 `frontend/src/types/diagnosis.ts` 一致
- 时间格式统一使用 ISO 8601（`2026-11-16T10:00:00Z`）
- 状态枚举：`pending`、`analyzing`、`completed`、`failed`

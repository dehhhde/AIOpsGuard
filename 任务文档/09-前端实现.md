# 阶段九：前端实现（数据展示优先）

## 一、任务概述

本阶段优先完成**前端数据展示**：先以 Mock 数据把页面、图表、交互全部做出来，后续再替换为真实接口。这样可以在诊断后端尚未实现的情况下，先确认信息架构与展示效果。

**优先级**：P1（当前主线）
**依赖**：阶段一（已完成）；真实数据对接依赖阶段六（应用服务与 API，未开始）
**范围**：`frontend/` 工程、页面、组件、Mock 数据、图表、Grafana 深链
**不在本阶段范围**：认证与权限（阶段十四）、多租户（阶段十五）、Grafana Dashboard 本身

**展示边界**：严格遵循 [前端与 Grafana 数据展示划分](../前端与Grafana数据展示划分.md)，原始时序看 Grafana，诊断业务看前端。

核心类型草案：

```ts
export type DiagnosisStatus = 'pending' | 'analyzing' | 'completed' | 'failed';

export interface RootCause {
  rank: number;
  cause: string;
  confidence: number;
  evidenceIds: string[];
}

export interface Evidence {
  id: string;
  type: 'METRIC' | 'LOG' | 'TRACE';
  summary: string;
  source: string;
  timeRange: { start: string; end: string };
  detail: Record<string, unknown>;
}

export interface DiagnosisSession {
  diagnosisId: string;
  serviceName: string;
  status: DiagnosisStatus;
  stage?: string;
  progress?: number;
  startedAt: string;
  finishedAt?: string;
  rootCauses: RootCause[];
  evidence: Evidence[];
}
```
